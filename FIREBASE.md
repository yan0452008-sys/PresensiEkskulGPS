# Dokumentasi Firebase Presensi Ekskul GPS

## Informasi Proyek
- Nama proyek: PresensiEkskulApp
- Database: Firebase Realtime Database
- Aplikasi: PresensiEkskulGPS

## Struktur Database
- `siswa`: menyimpan data siswa berdasarkan NIS.
- `presensi`: menyimpan catatan kehadiran ekstrakurikuler.
- `status_presensi`: menyimpan status presensi siswa.

## Fitur
- Login menggunakan NIS.
- Presensi ekstrakurikuler.
- Pengambilan lokasi GPS.
- Penyimpanan data presensi ke Firebase.
- Riwayat presensi.

Catatan: Akses database perlu dikonfigurasi dengan aman sebelum aplikasi digunakan kembali.
